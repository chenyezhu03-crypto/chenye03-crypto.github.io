# 微信小程序壳（WebView）

当前 H5 站点部署在 GitHub Pages 后，可用本目录在微信开发者工具中导入，用 **web-view** 加载线上版。

## 步骤

1. 将 `pages/index/index.js` 里 `H5_BASE` 改成你的已备案业务域名（须 HTTPS，并在小程序后台配置 web-view 合法域名）。
2. 微信开发者工具 → 导入项目 → 选本 `miniprogram` 目录，填入你的 AppID。
3. 真机预览前完成：用户隐私协议、类目（旅游资讯/工具）。

## 说明

- 支付、登录、分享需后续接 `wx.login`、商户号；当前与 H5 演示数据一致。
- 未配置域名前，开发者工具可勾选「不校验合法域名」仅本地调试。
