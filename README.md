# 投简 · 条件透视的智能简历代投

投简把岗位条件看清楚、把简历版本选对、把硬门槛岗位批量投出去。

## 特色

- **真实数据源**：国内演示源 + Remotive 开放 API + 自定义 JSON 导入
- **条件透视**：学历 / 专业 / 经验 / 性别标注结构化
- **可解释匹配**：通过 / 接近 / 缺口 + 匹配分
- **多版简历**：按岗位关键词自动切换技术向 / 业务向等版本
- **批量队列**：只投硬门槛通过项，自动生成自适应投递包

> 不接需要登录的第三方招聘账号爬虫。Remotive 岗位请保留原文链接与来源标注。

## 本地开发

```bash
npm install
npm run dev
```

## 构建与自测
